# Apple Developer Academy | Mackenzie

This repository gathers the projects I developed during my journey as a student at the Apple Developer Academy at Mackenzie. The main focus is the development of innovative solutions using the Apple ecosystem, exploring everything from programmatic interfaces in UIKit to immersive spatial computing experiences.

---

## Featured Projects

Below is a list of the main projects included in this repository, each focusing on different technologies and software engineering challenges:

### 1. Inheal
Project developed for the Swift Student Challenge, focused on helping young adults with anxiety. It utilizes sensory grounding techniques and breathing control.
* **Technologies:** SwiftUI, Timers, AppStorage, and Dynamic Animations.
* **Highlight:** Implementation of the 5-4-3-2-1 method to interrupt anxiety spirals.

### 2. Kid Task
Finalist app of the 13th edition of Campus Mobile (Instituto Claro). Created to assist in the inclusion of children with Autism Spectrum Disorder (ASD) in household routines.
* **Technologies:** SwiftUI, UIKit (UIImagePickerController), CoreData, and 3D Animations.
* **Highlight:** Interface focused on predictability and visual support to foster child autonomy.

### 3. Batuque
Exploration of spatial computing for the Apple Vision Pro. The application allows interaction with percussion instruments in an immersive environment.
* **Technologies:** visionOS, RealityKit, Reality Composer Pro, and Spatial Audio.
* **Highlight:** Mapping of native hand gestures to spatial audio triggers.

### 4. Próxima Estação: Cãofusão nos Trilhos
Real-time multiplayer game with a Brazilian theme, set in a train station inspired by Estação da Luz.
* **Technologies:** SpriteKit, GameKit (Game Center), GameController, and SwiftUI.
* **Highlight:** Synchronization of position data across multiple players via Game Center.

### 5. Articula
Tool designed to assist the physiotherapy recovery process, marking our first practical experience with interfaces built entirely via code.
* **Technologies:** UIKit (ViewCode), CoreMotion, and UserNotifications.
* **Highlight:** Use of the device's accelerometer for automatic counting of physical exercise repetitions.

---

## Technical Skills Developed

Throughout these projects, advanced iOS and visionOS development concepts were applied, including:

* **Language:** Swift (Swift Concurrency and MainActor isolation).
* **Architecture & UI:** SwiftUI, UIKit (ViewCode), MVVM, and Gestalt Principles.
* **System Frameworks:** CoreData for persistence, CoreMotion for sensors, and GameKit for multiplayer networking.
* **User Experience:** Accessibility-first design, Haptic Feedback, and Spatial Computing.
